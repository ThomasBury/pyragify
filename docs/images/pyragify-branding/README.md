# Pyragify — The Archivist (SVG identity kit)

Palette
- Soft charcoal / slate: `#2C323A`
- Ivory: `#F4F0E8`
- Vermilion: `#E76F51`

Contents: banner (1500 × 500), primary logo (1000 × 280), standalone icon (512 × 512), favicon (16, 32, 64). Every asset has a colored-background and transparent-background SVG.

All geometry is native SVG. The wordmark is editable SVG text using an Inter/Helvetica Neue/Arial font stack; for pixel-identical rendering across systems, substitute your chosen installed font or convert the wordmark to paths in a vector editor. Transparent versions have no background rectangle. Favicons deliberately simplify the emblem for small-size readability.
